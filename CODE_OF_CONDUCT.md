# Code of Conduct

All projects under the [`bundu-labs`](https://github.com/bundu-labs)
GitHub organisation adopt the
**[Contributor Covenant 2.1][cc]** as our code of conduct, mirroring
the wider Nyuchi Africa policy at
[`nyuchi/.github → CODE_OF_CONDUCT.md`](https://github.com/nyuchi/.github/blob/main/CODE_OF_CONDUCT.md).

The full text — including standards, scope, enforcement
responsibilities, and enforcement guidelines — is canonical at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.

## Scope

This Code of Conduct applies within all community spaces tied to any
`bundu-labs` repository — issues, pull requests, discussions, blogs,
and any official representation at events or in correspondence — and
when an individual is officially representing the project in public
spaces.

## Reporting

If you experience or witness conduct that violates this code, report
it privately. **Do not** open a public issue.

- **Email**: [hi@nyuchi.com](mailto:hi@nyuchi.com) with subject
  `[Code of Conduct] <brief description>`. Reports go to
  organisation leadership and are treated with strict confidence.
- **Platform-level abuse** on GitHub itself: use GitHub's
  [report abuse](https://github.com/contact/report-abuse) form.

Reporters will not be retaliated against, and reporter identity will
be kept confidential to the extent consistent with a fair review.

## Enforcement

Maintainers are responsible for clarifying and enforcing standards.
Enforcement decisions follow the
[Contributor Covenant Enforcement Guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines):
Correction → Warning → Temporary Ban → Permanent Ban.

[cc]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
